# Robot

`robot.glb` is generated by `tools/blender/robot.py` (own work, CC0). Materials: Shell, Visor, Eyes, Accent (recoloured per agent), Joint; animations: Idle, Walk, Type, Read, Carry, Handover, Wave, Think.
Rebuild: `/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python tools/blender/robot.py` (Blender 5.2).
Check: `python3 -I tools/blender/inspect_glb.py assets/models/robot/robot.glb`; previews: `Blender -b --factory-startup --python tools/blender/robot_preview.py -- OUT_DIR Idle:0 Walk:5`.
